# Contributing

This repository contains auto-generated test coverage reports. It is updated automatically by CI workflows from the source repository.

## How this works

1. CI workflow in [the-last-dance](https://github.com/xabierlameiro/the-last-dance) runs Jest with coverage
2. The coverage report is committed to `coverage/` in this repository
3. GitHub Pages serves the coverage report at the published URL

If you find a bug, please open an issue in the [source repository](https://github.com/xabierlameiro/the-last-dance).
