# Unit Test Coverage Archive

Auto-generated Jest test coverage report archive for [xabierlameiro/the-last-dance](https://github.com/xabierlameiro/the-last-dance), deployed to GitHub Pages.

## What’s in this repo

The `coverage/` folder contains the latest Istanbul HTML coverage report. It is updated automatically on every CI run.

## Viewing the coverage report

Open the [GitHub Pages site](https://xabierlameiro.github.io/unit-report/) to browse the interactive coverage report.

## Source

Tests are defined in [xabierlameiro/the-last-dance](https://github.com/xabierlameiro/the-last-dance) alongside their components.
